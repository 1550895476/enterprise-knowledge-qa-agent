# 复盘与下一步

## 投入与完成范围

- 实际用时：2天4小时
- 当前未完成：尚需使用候选人自己的在线模型录制并审核真实决策 Trace；私有仓库评审权限和最终 commit SHA 需要在提交前人工确认。









## 最难的问题

最难的是区分“检索到了候选”与“原文足以支持答案”。如果直接使用摘要，冲突制度很容易被错误地压成一个数字。因此当前实现要求先读取原文，再做冲突判断，并把适用范围、版本日期和原文一起返回。

另一个难点是让自动化测试可复现，同时不把规则分支伪装成真实模型决策。当前生产代码只接受在线模型；确定性测试桩放在 `tests/` 中，仅用于验证工具观察、停止条件和异常路径。

## 学习收获

- Agent 的关键不在框架名称，而在状态、工具观察和停止条件是否可审计；
- 引用必须来自实际读取的内容，不能只引用搜索标题；
- 失败路径和资料不足应成为一等输出，而不是异常日志里的隐含信息。

## 下一步

1. 让文档解析器抽取主题、数值、适用范围和生效/失效日期，支持更复杂冲突；
2. 增加固定评测集和模型版本对比，统计引用准确率、冲突召回率和无依据回答率；
3. 在接入真实企业知识库前增加权限过滤、审计日志和敏感信息脱敏。
